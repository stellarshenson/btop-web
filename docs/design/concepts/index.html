btop-web concepts

Base: ../onepage.html, the 1:1 btop render approved as the starting point. The ten concepts keep the host's mock data, all three GPUs, PCHIP charts, house chips, CONFIG-only settings and the 1440x900 one-viewport rule. They vary the layout, panel language, type scale, chart treatment and chrome.

all ten pass every checked rule at 1440x900, process table the only internal scroll

01classic-modern

The approved 1:1 btop geometry, refined: same boxes and proportions, system sans labels, mono numbers, hairline borders with a 1 px inner highlight, quiet accents, panel labels on the border line.

Borrowedbtop's box anatomy, Linear/Vercel panel restraint.

PASSexact 1440x900 fit, no failed rule

02terminal-grid

Terminal DNA taken literally: full monospace, ASCII-flavoured panel labels, inverted label tabs, a phosphor accent on near-black, 1:1 btop boxes, zero decoration beyond rules and type.

Borrowedbtop, htop, btm.

PASSexact 1440x900 fit, no failed rule

03band-rows

Full-width horizontal bands instead of columns: a CPU band (headline, inline PCHIP, 64-cell heatstrip), a MEM band (stacked bar, figures), a NET band (twin sparklines), a GPU band (three cells), and the process table as the bottom band filling the rest.

BorrowedActivity Monitor's bottom strip, Grafana rows, Tufte's small multiples.

PASSexact 1440x900 fit, no failed rule

04device-rail

Task Manager / Mission Center anatomy: a 220 px left rail lists CPU, memory, network, GPU 0, GPU 1 and GPU 2, each with a 40 px sparkline and one headline number; the right pane is the selected device's detail (graph, stats), with the process table beneath it.

BorrowedWindows Task Manager rail, Mission Center, GNOME Resources.

PASSexact 1440x900 fit, no failed rule

05grafana-panels

A 12-column panel dashboard: stat panels with a dominant number and a sparkline behind it, two gauge panels (CPU and memory), a time-series panel for network, a GPU table panel, and the process table as a panel.

BorrowedGrafana, Datadog host dashboards.

PASSexact 1440x900 fit, no failed rule

Variations of 05

Ten small imaginative variations of the accepted 05 page. Each keeps 05's Grafana panel language, palette, data and values, and changes one idea a reader sees at a glance.

05.01-border-titles

Every panel title rides the top border with the line breaking around it, and the header row disappears.

Readoutborder titles - twelve titles on the panel line, zero header rows

05.02-gauge-merged

Each radial gauge moves inside its stat panel, so twelve panels become ten and the charts take the freed height.

Readoutgauge merged - ten panels, two rings in their stat tiles, stat charts 104, 112 and 75 px against 05's 70 px

05.03-one-accent

Every series uses the theme's one accent hue in five brightness steps, with status colour only on values that carry status.

Readoutone accent - one hue stepped five ways, ok, warn and crit only on status values

05.04-boxed-values

Every value sits in its own bordered cell with its unit, in four aligned cell heights.

Readoutboxed values - every readout in a 1 px bordered cell, four aligned heights

05.05-stat-strip

CPU, memory, network in, network out and the process count collect into one five-tile strip across the top.

Readoutstat strip - five stat tiles in one strip, seven panels below

05.06-network-paired

Download and upload share one Network panel as two stacked plots on one time axis, one y scale and one legend.

Readoutpaired network - two plots, one shared axis, one legend

05.07-process-right

The process table becomes a full-height right column and the left grid rebalances around it.

Readoutprocess right - a 556 px full-height process column

05.08-core-strip

The 64 cores become one horizontal strip of per-core bars, and the freed height goes to the history charts.

Readoutcore strip - 64 bars in one 1422 px strip inside the 1424 px panel row

05.09-label-rail

Every panel's labels move to a narrow left rail and the values right-align against it on one shared row rhythm.

Readoutlabel rail - a 74 px label rail in every panel, values right-aligned on one rhythm

05.10-quiet-frame

Panel fills and head rules disappear, leaving hairline frames and small-caps titles on one calm surface.

Readoutquiet frame - transparent panels, 1 px frames, small-caps titles

06netdata-stream

Dense realtime stream: 12-16 small charts arranged in a tight grid, each with a title, current value and a rolling PCHIP line; the process table as one tall panel on the right.

BorrowedNetdata, Glances.

PASSexact 1440x900 fit, no failed rule

07table-first

Ops console: the process table is the hero at about 60% of the page, with a 64 px summary strip above carrying CPU, memory, network and the three GPUs as compact stat cells with inline sparklines; the CPU matrix collapses into a heatstrip.

Borrowedhtop's table-first view, Activity Monitor, Datadog's list-first pages.

PASSexact 1440x900 fit, no failed rule

08matrix-hero

The 64-core matrix is the visual centre: a large 8x8 heat grid with per-core values, sized to dominate the left two thirds; the CPU history runs behind/above it; memory, network and the three GPU cells form a right column; the process table is a bottom-right panel.

Borrowedbtop's core matrix, heatmap dashboards, Windows Task Manager's logical-processor view.

PASSexact 1440x900 fit, no failed rule

09small-multiples

Tufte: a vertical stack of labelled sparkline strips - CPU, memory, swap, network down, network up, GPU 0, GPU 1, GPU 2, disk read - each with the value at the line's end and no boxes except hairline rules; the process table is a compact panel on the right.

BorrowedTufte sparklines, Activity Monitor history graphs, FT/Economist chart economy.

PASSexact 1440x900 fit, no failed rule

10paper-light

The light counterpart: paper-white surfaces, thin rules, muted ink, one warm accent, btop's geometry but airier spacing and a serif-free editorial type scale.

BorrowedLinear light, Notion/Stripe dashboards, print data tables.

PASSexact 1440x900 fit, no failed rule

Adaptive and responsive

The four pages below start from 05.06-adaptive-base, which changes 05.06-network-paired in three ways: a GPU load plot with one line per GPU and a per-GPU legend replaces the GPU cards panel, the cores move to the middle of band 3, and each gauge carries 11 ticks with its readout inside the arc.

05.06-adaptive-baseStarting page, no breakpoints

The desktop grid at every size: it fits 1440x900, and below 1440x900 it cuts text. The four pages below avoid that, each with its own strategy.
