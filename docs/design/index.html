Design system at a glance

Palette

Five families, ten variants: eight file-backed pairs plus the generated Default pair. Components read semantic tokens only; raw btop values are confined to chart fills after the 3:1 clamp and never carry text.

Graphs

PCHIP, Fritsch-Carlson slopes, on every sparkline and history chart. 120 knots for history; knots land on their timestamps; monotone runs stay monotone; the curve never overshoots the sample extremes. Measured 120-knot rebuild: PCHIP 0.0995 ms median, natural cubic 0.1045 ms; the cubic scheme was 5% slower and overshot at 13 sampled points, so PCHIP stays.

Performance budget

One sampler tick per interval, fanned out to every client; static facts cached. No per-frame work, no timer, no rAF loop: the DOM changes only when a fragment arrives. Hidden tabs stop applying snapshots and resync on show. Tick 2.1 ms of an 8 ms budget; chart rebuild under 4 ms at 120 knots.

Read-only

Read-only is the default and visible state. The server refuses every mutating request with a typed 403; the UI disables terminate, kill, signal and priority with the reason in view. No unlock toggle exists.

Type and space

Scale 11, 12, 13, 14, 16, 20, 28, 40 px. Spacing 2, 4, 8, 12, 16, 24, 32, 48, 64 px on a 4 px base. Radii 4 px controls, 8 px panels, 999 px pills. 1 px borders, 2 px panel top rules, no shadows.

Accessibility

WCAG AA in every variant; semantic landmarks; focus-visible rings; reduced motion honoured; no colour-only encoding. Status carries a word, sort carries aria-sort, read-only carries the words READ-ONLY.
